# 公文写作提示词需求规格书（原文修订版）

## 一、任务定位

本任务不是重新起草一篇通知，而是以第三十五届“冯如杯”竞赛通知为正文底稿，对其进行最小范围修订，生成一篇完整的第三十六届通知。

第三十五届通知是主模板，第三十四届通知只用于辅助判断连续两届稳定沿用的章节顺序、段落职责、表达密度和排版格式。

下方“本届变更清单”不是输出大纲，不能只写清单涉及的部分。输出必须是一篇完整通知，未列入变更清单的章节和段落，应尽量直接沿用第三十五届原文。

## 二、材料使用方式

必须按以下方式使用上传材料：

1. 第三十五届的通知必须作为正文底稿使用。
3. 尽量摘录第三十五届通知的完整正文，内容结构至少覆盖开头引入、指导思想、组织机构、时间安排、申报工作、评审工作、交流活动、工作要求、附件、落款和版记。
4. 第三十四届的通知只作为辅助材料，不作为第三十六届正文事实来源。

## 三、硬性规则

1. 以第三十五届原文为底稿修订，不按自己的理解重新组织全文。
2. 没有明确列入“本届变更清单”的内容，默认不改。
3. 能做届次、年份、日期、单位、人员、赛道、附件名称等变量替换的地方，只做变量替换。
4. 只有变量替换后前后文不通顺时，才允许做局部顺句。
5. 禁止把未变更章节概括成“继续按照第三十五届通知执行”“参照上届执行”“按原通知执行”等表述。
6. 禁止删除第三十五届原文中仍然适用的章节、段落、过渡语、工作要求和附件项。
7. 禁止把“本届变更清单”的标题、编号或说明文字写进正式通知正文。
8. 禁止把自然段改成提纲，禁止新增未在第三十五届原文中出现的分点结构。
9. 输出篇幅应接近第三十五届原文；如果明显短于第三十五届，通常说明发生了摘要化或漏段，必须补回。
10. 禁止用概括性新段落替代第三十五届原文段落。开头依据段、指导思想、申报工作、评审工作、交流活动和工作要求尤其不得重写成摘要。

## 四、必须保留的完整通知结构

生成正文时，必须保留第三十五届通知的完整结构和顺序，包括但不限于：

标题、主送单位、开头依据段、赛制说明段、承接句、指导思想、组织机构、时间安排、申报工作、评审工作、交流活动、工作要求、特此通知、附件清单、落款日期、抄送和版记。

这些结构中，除下方明确列出的变更位置外，其余内容按第三十五届原文保留。

## 五、生成流程

1. 先完整读取第三十五届通知，把它作为待修订正文。
2. 再读取第三十四届通知，只用于确认哪些结构和写法是稳定格式。
3. 按“本届变更清单”逐项在第三十五届正文中定位对应位置。
4. 对定位到的位置做最小替换。
5. 替换后通读全文，重点检查有没有漏掉未变更章节，有没有把未变更内容改成概括句，有没有新增提纲式分点。
6. 最终只输出修订后的第三十六届通知正文，不输出修改说明。
