# 北航语境

本文件约束北航校内公文的语境、称谓、常见主题和高风险口径。

## 高频写作场景

北航公文和综合材料应优先覆盖以下场景：

- 通知，尤其是印发制度、修订制度、组织会议、报送总结计划、开展专项工作。
- 制度类文本，包括管理办法、实施办法、实施细则、管理规定、议事规则、章程、工作规则。
- 会议纪要，包括党政办公室例会、部长办公会、委员会会议、专题推进会。
- 意见、方案、总结计划、通报、公示、报告、函等综合材料。
- 新闻类文章，包括学校要闻、综合新闻、信息公告、学术及文化活动、媒体北航、学院动态、通知公告、采购公告、竞价公示、招生招聘等；这类材料按新闻文章处理。

## 常见主体和对象

可用主体包括学校党委、学校行政、党政办公室、机关部处、学院、直属单位、委员会、工作领导小组等。不得从既有材料中猜测当前发文主体。

常见对象包括：

- 各单位
- 各学院、各有关单位
- 各学院、部处、直属单位
- 各二级单位
- 相关职能部门或具体学院

称谓必须以用户材料为准。用户未给对象时，普通校内通知可用“各单位：”作为草稿称谓，但正式交付应提示核对。

## 高校行政语体

北航公文应体现高校行政场景，围绕人才培养、科学研究、学科建设、师资队伍、学生工作、国际合作、实验室安全、财务资产、信息化、校园运行、党建和思想政治工作展开。

避免错误套用：

- 不把校内管理事项写成地方政府治理、营商环境、产业招商、基层治理等口径。
- 不把制度办法写成新闻宣传稿。
- 不把总结汇报写成只有口号和排比的宣传材料。
- 不把学院、部处职责写成行政执法、审批许可或监管处罚权。

## 常用稳妥表达

可参考但不可机械堆叠：

- 为进一步规范……，提高……，根据……，结合学校实际，制定本办法。
- 为做好……工作，现将有关事项通知如下。
- 现将有关情况报告如下。
- 请各单位结合实际，认真抓好落实。
- 拟请学校协调解决……。
- 经研究，现就有关事项函复如下。

## 禁止无依据生成的口径

以下内容必须有用户材料或明确依据：

- “经学校党委常委会审议通过”“经校长办公会研究决定”“学校研究决定”。
- “原则同意”“批准”“予以备案”“同意实施”等审批结论。
- 发文字号、制度废止信息、正式发布日期、施行日期。
- 经费安排、编制岗位、招生指标、学位授予、人事任免、处分处理。
- 涉密、保密、意识形态、安全事故、纪律检查等结论性判断。
- “全国首个”“国内领先”“显著提升”“全面完成”“形成长效机制”等强评价。

## 北航特色内容处理

- 涉及学院、部处和直属单位时，职责分工要按照材料写，不根据常识补。
- 涉及会议纪要时，只有材料明确记录，才写“会议认为”“会议同意”“会议明确”“会议要求”。
- 涉及制度类文本时，优先使用条款式表达，少用宣传性形容词。
