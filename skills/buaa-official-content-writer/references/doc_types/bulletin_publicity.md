# 通报、公示、公告、通告

适用于情况通报、工作通报、结果公示、名单公示、事项公告、采购公告、竞价公示、成交公告、校内通告等。

## 通报

结构：

```text
标题
主送对象
一、基本情况
二、主要问题/结果/做法
三、工作要求
落款
日期
```

表彰、批评、情况通报语气不同。批评和问题通报必须有材料依据，避免扩大责任。

## 公示

结构：

```text
标题
公示事项
公示名单或结果
公示时间
异议受理方式
落款
日期
```

名单、期限、联系人、电话必须来自材料。

## 公告/通告

用于需要一定公开范围知悉或遵守的事项。校内普通事务优先用通知，不主动升级为公告或通告。

## 采购公告/竞价公示/成交公告

结构：

```text
标题
项目名称
采购或公示内容
时间安排
响应或异议方式
联系人及电话
落款
日期
```

采购金额、成交单位、项目编号、联系人、电话、异议期限等必须来自材料，不得补造。

## 风险

- 不编造名单、排序、处分、处理结果。
- 不把内部通知写成面向社会公告。
- 涉及负面名单、纪律、安全、财务风险时，语气要客观克制。
