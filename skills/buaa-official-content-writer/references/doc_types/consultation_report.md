# 征求意见情况报告

适用于制度草案征求意见情况报告、制度办法送审说明和修订说明。它不是普通工作报告，重点是说明征求范围、收到意见、采纳情况和修改结果。

## 基本结构

```text
# 《……》征求意见情况报告

《……》已于……面向……征求意见。现将征求意见情况报告如下：

一、征求意见基本情况

二、意见建议分类情况

三、采纳和修改情况

四、未采纳意见及理由

五、结论
```

如果意见很少，可写成短段式：

```text
共收到……条修改建议，主要归类为：
1.……
2.……
以上建议……采纳，已进一步完善……
```

## 必需信息

- 制度或文件名称。
- 征求意见时间。
- 征求对象。
- 收到意见数量。
- 主要意见类别。
- 采纳、部分采纳、不采纳情况及理由。

## 风险

- 不编造意见数量、征求对象和采纳结论。
- “全部采纳”“无不同意见”必须有材料支持。
- 不把征求意见报告写成制度正文或工作总结。
