# 决定、决议、批复

这些是北航《公文处理办法》列明的通用公文种类，但在普通写作请求中相对低频，且权限要求高。只有用户明确要求或材料明确显示适用时才使用。

## 决定

适用于对重要事项作出决策部署、奖惩有关单位和人员、变更或撤销下级不适当决定事项。

风险：普通工作安排不要写成决定；奖惩、机构、人事、经费等必须有正式依据。

## 决议

适用于会议讨论通过的重大决策事项。必须有会议名称、审议过程和通过结果材料。

风险：不得根据用户一句“会议讨论了”生成“会议决议”。

## 批复

适用于答复下级单位请示事项。

基本结构：

```text
标题
主送对象
开头：你单位《关于……的请示》收悉
批复意见：原则同意/不同意/请按要求办理
工作要求
结语：此复
落款
日期
```

风险：不得替有审批权单位作出“同意”结论，除非用户明确提供批复意见。
