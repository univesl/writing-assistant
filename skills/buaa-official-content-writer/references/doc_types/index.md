# 北航文种索引

本索引用于先判断文种，再读取具体文种文件。北航内容写作应优先覆盖通知、制度、纪要、方案意见、总结计划、公告公示等高校治理材料。

## 高频文种

| 场景 | 读取文件 | 关键结构 |
| --- | --- | --- |
| 普通通知、会议通知、报送通知、印发/修订通知 | `notice.md` | 背景目的、具体事项、工作安排、要求、附件 |
| 校内请示、申请支持、申请批准 | `request.md` | 缘由、依据、事项说明、请示事项 |
| 工作情况报告、办理情况报告、问题情况报告 | `report.md` | 基本情况、主要工作、问题、下一步 |
| 商洽、邀请、征求意见、复函 | `letter.md` | 来函/发函背景、事项说明、逐项回应、结语 |
| 例会、专题会、委员会会议纪要 | `minutes.md` | 会议信息、议题、听取/认为/同意/明确/要求 |
| 管理办法、规定、实施细则、议事规则、章程 | `regulation.md` | 总则、职责、程序/要求、监督、附则 |
| 实施方案、行动方案、专项工作方案 | `plan.md` | 总体要求、目标、任务、进度、责任、保障 |
| 指导意见、实施意见、若干意见 | `opinion.md` | 总体要求、原则、重点任务、组织保障 |
| 工作总结、工作要点、重点工作计划 | `summary_plan.md` | 主要工作、成效、问题、下一步或重点任务 |
| 通报、公示、公告、通告、采购公告、竞价公示 | `bulletin_publicity.md` | 情况/结果、名单或事项、期限、要求 |
| 新闻类文章、网站稿、活动报道、宣传稿 | `news.md` | 导语、主体段落、结尾 |
| 决定、决议、批复 | `decision_approval.md` | 只在材料和权限明确时使用 |
| 征求意见情况报告、制度送审说明 | `consultation_report.md` | 征求范围、意见数量、分类、采纳情况 |

## 路由提醒

- “关于印发《……》的通知”通常包含两层：通知壳读取 `notice.md`，附件制度读取 `regulation.md`、`plan.md` 或 `opinion.md`。
- 用户说“报告”但有明确“申请批准/协调解决”事项时，改按 `request.md`。
- 用户说“方案”但内容是长期制度规则时，改按 `regulation.md`。
- 用户只给会议记录时，按 `minutes.md`，不得编造会议决定。
