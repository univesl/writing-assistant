# 函与复函

适用于不相隶属单位之间商洽工作、询问答复、邀请参会、征求意见、回复来函等。北航校内部门之间也可用较协商的函件语气。

## 类型

- 商洽函：说明事项、提出协作请求、明确反馈方式。
- 征求意见函：说明征求对象、材料名称、反馈期限和方式。
- 邀请函：说明活动背景、时间地点、邀请对象、回执要求。
- 复函：逐项回应来函事项，说明办理意见和边界。

## 基本结构

```text
标题
主送对象
开头：来函背景或发函目的
正文：事项说明/需协助事项/逐项答复
结语：专此函达/特此函复
落款
日期
```

## 北航写法

- 校内函件保持协商、审慎、清楚，不写命令式口吻。
- 对外复函避免超出学校或本单位权限作出承诺。
- 征求意见函只写反馈要求和截止时间；是否写“逾期视为无意见”必须看用户要求和适用规则，默认不写。

## 风险

- 复函必须逐项回应来函事项。
- 不使用“同意、批准、保证、承诺”等强结论，除非材料明确授权。
- 联系人、电话、邮箱没有材料不得编造。
