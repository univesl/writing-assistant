# 会议纪要

适用于党政办公室例会、部门部务会、委员会会议、专题推进会、工作协调会等北航高频会议材料。会议纪要常用结构为：会议基本信息、议题列表、逐项“会议听取/认为/同意/明确”。

## 基本结构

```text
# 会议纪要标题

时间：
地点：
主持人：
出席人：
列席人：
记录人：

会议研究如下议题：
1.……
2.……

一、研究……

会议听取了……
会议认为，……
会议同意，……
会议明确，……
会议要求，……
```

不是所有纪要都需要完整字段。缺主持人、列席人、记录人时，不编造。

## 状态词

- “会议听取了”：材料只说明听取汇报。
- “会议研究了/讨论了”：材料说明进行了研究讨论，但未形成决定。
- “会议认为”：材料明确有判断意见。
- “会议同意”：材料明确形成同意意见。
- “会议明确/要求”：材料明确有安排、责任或后续动作。

## 北航写法

- 议题按“一、二、三”排列。
- 每个议题先交代“会议听取了……汇报”，再写形成意见。
- 涉及需上会审议的事项，可写“有关方案提请……审议决定”，但必须有材料支持。

## 风险

- 不把汇报内容写成会议决定。
- 不编造参会人员、会议时间、地点。
- 不新增编制、经费、机构级别、人事安排等结论。
