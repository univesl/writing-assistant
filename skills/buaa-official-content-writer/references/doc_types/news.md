# 新闻类文章

适用于新闻类文章、网站稿、活动报道和宣传稿。

## 结构

1. 标题简洁明确，突出人物、事项或活动结果。
2. 正文通常采用导语加主体段落的写法。
3. 导语交代时间、地点、单位、事项和结果。
4. 主体段落按活动经过、主要做法、现场情况、成果和后续安排展开。
5. 结尾可写意义或下一步工作，但必须有材料支撑。

## 写作要求

- 以可核验事实为主，不补造会议结论、领导表态、数据、排名和成绩。
- 零散素材或要点表优先提炼文章标题、发布时间、人物、单位、事项、结果和关键数据，再组织成完整文章。
- 原始素材中有可直接保留的表述时，可按新闻体适度整理。

## 禁止项

- 不写“现将有关情况报告如下”等公文套话。
- 不把新闻稿改写成制度、请示或总结计划。
- 不把宣传性词语直接升级为事实未证实的结论。
