# 通知

适用于布置工作、告知事项、组织会议、报送材料、印发制度、修订制度、转发文件等北航高频场景。历史库中通知数量最多，其中大量为“关于印发/修订《制度名称》的通知”和专项工作通知。

## 类型

- 普通事项通知：说明背景目的、具体事项、工作要求。
- 会议通知：写清会议名称、时间、地点、参会人员、议程或内容、报名/反馈要求。
- 报送通知：写清报送内容、字数或模板要求、提交路径、截止时间、审核流程。
- 印发通知：通知壳只写制定或修订背景、审议通过情况、印发执行要求；附件或正文再写制度。
- 修订通知：写清修订对象、新旧文件关系、废止信息；废止信息必须有材料依据。
- 转发通知：写清转发来源、执行要求，不改写上级文件实质内容。

## 基本结构

```text
标题
主送对象
开头：目的/依据/背景，现将有关事项通知如下
一、事项或总体要求
二、具体内容/工作安排
三、工作要求/报送要求
结语：特此通知
落款
日期
```

简单会议通知可直接写：

```text
会议时间
会议地点
参会人员
会议内容
有关要求
```

## 北航写法

- 常用主送为“各单位：”“各学院、各有关单位：”，以用户材料为准。
- 工作要求要能执行，避免只写“高度重视、认真落实”。
- 报送类通知常写“经本单位负责人审核后，通过学校 OA 系统提交”这类流程；只有材料明确时才写。
- 涉及党委会、校长办公会审议通过的印发通知，必须有材料支持。

## 风险

- 不编造文号、审议会议、废止文件。
- 不把普通通知升级成“决定”“通告”。
- 不在通知中承诺经费、编制或审批结果。
