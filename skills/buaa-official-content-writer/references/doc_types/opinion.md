# 意见

适用于指导意见、实施意见、若干意见、原则意见等。北航历史文件中意见常用于党建、学生工作、教师队伍、学风建设、调查研究、文化建设等方向。

## 基本结构

```text
# 关于……的意见

一、总体要求
二、基本原则
三、重点任务
四、组织保障
```

也可按“提高认识、明确重点、完善机制、抓好落实”组织，但应避免空泛。

## 写作重点

- 意见重方向性、原则性和政策措施，比方案更强调指导和规范。
- 每条意见应包含明确对象、工作方向和落实要求。
- 适合提出长期机制、工作原则、重点举措，但不能越权设定硬性审批或处罚。

## 北航写法

- 用于校内治理时，应结合学院、部处、直属单位等主体关系。
- 可以写“各单位结合实际抓好贯彻落实”，但前文要有具体任务。
- 对教师、学生、科研、党建等领域要保持高校语境。

## 风险

- 不把意见写成制度条款或宣传倡议。
- 不编造上级政策依据和学校决策部署。
- 不把一般建议写成强制义务。
