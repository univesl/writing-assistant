# 方案

适用于实施方案、行动方案、专项工作方案、建设方案、改革方案。北航历史文件中方案常用于党建、人才培养、课程思政、体育美育、实验室安全、国际合作等专项工作。

## 基本结构

```text
# ……实施方案

一、总体要求
二、工作目标
三、主要任务
四、进度安排
五、责任分工
六、保障措施
```

根据材料可调整为“指导思想、基本原则、重点任务、组织实施、工作要求”。

## 北航写法

- 方案应回答做什么、谁来做、怎么做、何时做、如何保障。
- 学校层面方案可体现校院两级协同、职能部门牵头、学院主体责任，但必须有材料依据。
- 重点任务要围绕人才培养、科研组织、队伍建设、治理服务等实际工作，不堆抽象口号。

## 风险

- 责任单位、时间节点、考核验收没有材料时不得编造。
- 不把方案写成总结，不把拟开展工作写成已完成成效。
- 涉及跨部门协同，可用“建议由……牵头，会同……推进”，但正式责任仍需用户确认。
