# 报告

适用于汇报工作、反映情况、说明办理结果、提出建议。报告以陈述和说明为主，不要求上级批准。

## 类型

- 工作情况报告：背景、工作开展、成效、问题、下一步。
- 办理情况报告：交办事项、办理过程、办理结果、后续安排。
- 问题情况报告：基本情况、原因分析、已采取措施、下一步建议。
- 征求意见情况报告：见 `consultation_report.md`。

## 基本结构

```text
标题
主送对象
开头：根据要求或工作安排，现将有关情况报告如下
一、基本情况
二、主要工作/办理情况
三、存在问题
四、下一步工作
落款
日期
```

如果材料只支持其中部分内容，应减少章节，不补造问题或下一步。

## 北航写法

- 面向学校领导的报告要突出决策相关事实和待关注问题。
- 工作总结式报告可写主要做法、成效、问题和下一步，但成效必须有数据或事实支撑。
- 办理报告要回应交办事项，不能泛泛写工作成绩。

## 风险

- 报告不得夹带“请批准、请协调解决”等请示事项；有这类诉求应改为请示。
- 问题和不足要稳妥，不把未经确认的问题写成严重结论。
- 不编造“已完成、已形成、已建立”等完成状态。
