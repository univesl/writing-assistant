# 请示

适用于向学校、校领导、上级机关或有审批权限的单位请求批准、协调、支持或解决事项。北航《公文处理办法》单列“校内请示报告”，一般性事项也应参照公文拟制规范。

## 判断

有明确“请批准、请支持、请协调解决、拟请同意、申请经费/编制/指标/政策支持”等目的时，优先判断为请示，而不是报告。

## 基本结构

```text
标题
主送对象
一、请示缘由
二、有关情况和依据
三、请示事项
结语：妥否，请批示
落款
日期
```

短请示可不分标题层级，但必须把“为什么请示、请示什么、请求谁批”写清楚。

## 必需信息

- 主送对象或拟报校领导/单位。
- 请示主体。
- 一件明确事项。
- 具体请求内容。
- 事实依据或工作必要性。

## 北航写法

- 校内请示常涉及部门向学校、学院向学校、专项工作组向校领导请示。
- 请示事项应集中、可批复，不夹带长篇成绩总结。
- 涉及多个单位时，只写“已征求……意见”或“建议会同……”必须有材料依据。

## 风险

- 一文一事，不多头主送。
- 不写“请阅知”作为请示核心。
- 不替校领导写审批结论。
- 金额、编制、岗位、招生指标等数字必须来自材料。
