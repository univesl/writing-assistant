# 总结计划

适用于年度工作总结、阶段性总结、工作要点、重点工作计划、总结和计划报送材料。总结计划类材料应做到摆事实、列数据、文字精练，重点工作计划应突出一流导向、目标明确、措施可行。

## 工作总结结构

```text
# ……工作总结

一、总体情况
二、主要工作和成效
三、存在问题
四、下一步工作
```

如材料不足，可只写“主要工作”“问题不足”“下一步考虑”，不补造成效。

## 重点工作计划结构

```text
# ……重点工作计划

一、总体思路
二、重点任务
三、保障措施
```

重点任务建议 3-5 条，突出目标、举措和预期结果。事务性、常规性工作不宜占主要篇幅。

## 北航写法

- 机关部处总结偏“履行管理职责、推动学校重大工作、服务保障”。
- 学院和教学科研单位总结偏“学科建设、人才培养、科技创新、教师队伍、国际合作、党建和组织运行”。
- 总结要突出创新举措和亮点成绩，但必须有事实、数据或材料支撑。

## 风险

- 不把没有数据支撑的事项写成显著成效。
- 不用“全面完成、成效显著、国内领先”等强评价，除非材料明确。
- 下一步工作应回应问题和目标，不泛泛表态。
