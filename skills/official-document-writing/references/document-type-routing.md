# 文种与任务路由

本文件用于规划、提纲和审查阶段。判断文种时优先看行文目的、发文者与收文者关系、是否需要对方批准或回复，不只看用户标题关键词。

## 任务类型

- 起草：写一份、起草、拟一个、生成、形成某类公文或材料。
- 参考写作：参考、仿照、结合若干材料生成新稿；需先判断材料用途。
- 回复来文：围绕来函、意见、问题清单逐项回应。
- 改写修订：把已有正文改正式、润色、压缩、扩写、补充、只改选区。
- 审查把关：检查事实、格式、逻辑、政策依据、语言和风险。

## 常用文种

- 通知：部署工作、告知事项、组织会议活动、报送材料、印发制度。重点写清对象、事项、方式、时限和要求。
- 请示：向上级请求指示或批准。一文一事，通常只主送一个上级，结语可用“妥否，请批示”。
- 报告：向上级汇报工作、反映情况、提出建议，不要求批复。不得夹带请批事项。
- 批复：答复下级请示。应准确引用来文；无来文标题或文号时不得编造。
- 函/复函：不相隶属或平行单位商洽、询问、邀请、征求意见、答复事项。承诺和意见必须有授权依据。
- 会议纪要：记载会议情况和议定事项。材料只说“研究讨论”时，不升级为“会议决定”。
- 通报：表彰、批评或告知典型情况。应有事实和范围，不写成普通通知。
- 通告：在一定范围公布应当周知或遵守的事项。面向国内外重大法定事项才考虑公告。
- 意见/方案：提出原则性措施、实施路径、任务分工和保障安排。规模服从材料，不强行长篇化。
- 总结/汇报材料：总结工作情况、成效、问题和下一步安排。没有数据时使用克制定性表达。
- 制度办法：管理办法、规定、细则、规则、章程等条款化文件，应另按制度 Skill 处理。

## 北航高频场景

- 校内通知：竞赛、会议、申报、评审、报送、培训、活动、材料征集。
- 请示/报告：向学校、校领导、上级部门请求批准或汇报情况。
- 函/复函：校内外单位商洽、协作、征求意见、逐项回复。
- 纪要：专题会、委员会会议、工作推进会。
- 总结计划：年度工作总结、工作要点、专项工作计划。
- 通报公示：名单、结果、事项、处理情况。

北航事务默认使用高校行政语体，不主动套用地方政府治理口径、企业宣传口径或泛化政策口号。

## 易混边界

- “报告申请经费”更接近请示；报告不得请求批准。
- 函由隶属关系决定，不能因为事项重要就改成请示或通知。
- 纪要不能把未提供的参会信息、会议结论和责任时限补齐。
- 决定、决议、命令、公报、公告、议案对主体、权限和程序要求高；用户未提供合法程序时只能提示核验。
- 新闻稿、宣传稿、简报属于事务材料，不应伪装成正式法定公文。

## 追问边界

只追问会影响方向、对象、结论或风险的信息：发文主体、主送对象、请示事项、来函事项、制度适用范围、会议议定事项、经费金额、人事安全涉密等关键事实。不为了完整格式追问文号、签发人、印章、版记和页码。
