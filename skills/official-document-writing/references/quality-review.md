# 公文质量检查

按风险顺序检查，优先报告明确、可操作、会影响正式使用的问题。

## 高风险

1. 事实与依据：政策、文号、数字、人名、单位、日期、金额、附件和审批结论是否均有来源；推断是否被写成事实。
2. 权限与程序：发文主体是否有权作出决定、处罚、承诺、审批或经费安排；是否编造会议决定、领导指示或制度依据。
3. 文种与方向：请示是否一文多事或多头主送，报告是否夹带请批事项，函/复函是否遗漏来函事项或越权承诺。
4. 高敏事项：经费、编制、岗位、人事、招生、学位、安全、保密、意识形态、纪律处分等是否有明确材料支撑。

## 中风险

1. 标题、主送、正文目的、结语和落款是否匹配同一文种。
2. 事项是否形成闭环：主体、动作、对象、条件、时限、报送方式和反馈要求是否在材料允许范围内写清。
3. 参考材料使用是否越界：结构/风格材料中的旧事实是否误入正文，历史样文是否被当成当前事实。
4. 参考写作是否把底稿摘要化、漏章节、漏附件，或用“参照上届执行”等概括句代替具体内容。

## 语言与格式

- 删除写作说明、检索说明、聊天痕迹和“本文将从……”等旁白句。
- 警惕连续排比、机械三段式、口号式收尾、空泛抽象词和同义词乱换；只有成组影响信息密度时才判为明显问题。
- 不为“去 AI 味”改动事实、引用、术语、否定范围和状态强度。
- 中文正文使用全角标点，层级依次采用“一、”“（一）”“1.”“（1）”。
- 不把 DOCX 排版问题误报成 Markdown 正文问题；Markdown 只检查正文层级和内容边界。

## 审查输出

只报告有依据的问题，按严重程度给出最小范围修改建议。没有明显问题时说明“未发现明显内容风险”，并提示正式使用前仍需人工确认事实、依据和发文权限。
