# 公文质量检查

按风险顺序检查，不追求机械覆盖所有版式项目。

1. 事实与依据：政策、文号、数字、人名、单位、日期是否均有来源；推断是否被写成事实。
2. 文种与方向：文种是否符合隶属关系、目的和回应要求；报告是否夹带请示，函是否误用上下行文。
3. 权限与语气：发文主体是否有权作出相关决定、处罚或承诺；对上、对下和平行行文语气是否得当。
4. 内容闭环：事项是否有主体、动作、对象、条件和必要时限；请求或答复是否明确。
5. 结构与结语：标题、主送、正文层级和结语是否与文种匹配；编号是否连续。
6. 语言：删除空话、重复、口语和过度修饰；保留必要限定条件。
7. Markdown 边界：正文中不写来源、审查意见、系统说明、代码围栏或旧协议标记。

字体字号、页边距、页码、印章和版记应在 DOCX 模板/导出阶段检查；仅凭 Markdown 不宣称已符合全部 GB/T 9704-2012 版式要求。
